chatmesh

Anonymer Messenger. Nachrichten verschwinden von selbst, wie ein Gespräch im echten Leben.

chatmesh läuft auch im normalen Browser.
Der Server speichert dabei weder deine IP-Adresse noch eine Gerätekennung noch Uhrzeiten. Unterwegs im Netz (Internetanbieter, Zwischenstellen) ist deine IP-Adresse im normalen Browser aber grundsätzlich sichtbar. Wenn du auch das verbergen willst, nutze chatmesh über Tor, so geht es:

Was bringt Tor zusätzlich?

Tor verschleiert deine echte IP-Adresse, indem alle Anfragen über drei zufällige Server weltweit geleitet werden. Niemand auf der Strecke sieht gleichzeitig Absender und Ziel.

Bei der Onion-Adresse (.onion) bleibt die Verbindung komplett im Tor-Netz.

Was immer gilt, mit und ohne Tor: Der Server speichert keine IP-Adresse, keine Gerätekennung, keine Uhrzeiten, keinen Namen und keine Adresse. Nur namenlose verschlüsselte Blöcke. Die Schlüssel dazu haben nur du und dein Gegenüber, sie liegen nie auf dem Server. Beweis ansehen
