chatmesh: Beweis

Zur App

Hier kann jeder nachprüfen, wie dieser Server arbeitet. Speicherformat und Quelltext sind nicht von Hand eingetragen: Der laufende Server liest sie selbst aus seiner echten Datenbank und seinen echten Dateien.

1. Hier stehen bewusst keine Zahlen

Wie viele Menschen chatmesh benutzen, wie viele Nachrichten oder Dateien unterwegs sind: Das steht hier nicht, und der Server zählt es auch nirgends mit. Solche Zahlen würden etwas über die Nutzer verraten. Wir wollen es selbst nicht wissen.

  • Kein Zähler, keine Statistik, kein Protokoll. Der Server führt keine Liste, wer wann da war, und wertet nichts aus.
  • Alles sieht gleich aus. Jede Nachricht ist ein namenloser, verschlossener Block in fester Größe, ohne Absender und ohne Empfänger. Ob in einem Block ein Text, ein Bild oder nur Füllstoff steckt, kann der Server nicht erkennen.
  • Schein-Verkehr. Jede geöffnete App und ein eigener Dienst auf dem Server legen ständig Schein-Blöcke und Schein-Konten an und löschen sie wieder, in unregelmäßigen Abständen. Sie sehen aus wie echte. Welche echt sind, steht nirgends, auch wir können es nicht nachsehen.
  • Löschen. Ein Block wird gelöscht, sobald das Gegenüber den Chat öffnet. Liegengebliebenes verschwindet nach ein bis zwei Wochen von selbst.
  • Rechenaufgabe statt Überwachung. Weil der Server niemanden an einer IP-Adresse erkennt, muss jede Einlieferung eine kleine Rechenaufgabe mitbringen. So lässt er sich nicht billig mit Müll füllen, ohne dass er jemanden beobachten müsste.

2. So speichert der Server (Speicherformat)

Das ist der echte Bauplan der Datenbank, aus ihr selbst ausgelesen. Jede Spalte, die es gibt, steht hier.

lädt …

Zeitangaben, ehrlich aufgezählt: Blöcke tragen nur die Kalenderwoche, damit Liegengebliebenes nach einiger Zeit verschwindet. Ein Konto-Block trägt nur einen groben Abschnitt von vier Wochen (wann er zuletzt gespeichert wurde), damit ein Jahr lang unbenutzte Konten entfernt werden können. Die laufende Nummer eines Blocks ist nur eine Reihenfolge. Sonst gibt es keine Zeitangaben.

3. Der Quelltext, der gerade läuft

Die komplette Technik ist offen: Server, App, Verschlüsselung und der Dienst für den Schein-Verkehr. Unten steht jede Datei mit ihrer Prüfsumme (SHA-256). Ein Klick zeigt die Datei so, wie sie gerade läuft. Der Server startet nur, wenn seine Dateien zu den hinterlegten Prüfsummen passen.

4. Selbst nachprüfen, von außen

Glauben musst du uns nichts. Im öffentlichen Quelltext-Verzeichnis liegt ein kleines Prüf-Programm. Es lädt alles, was dieser Server gerade ausliefert, und vergleicht es Datei für Datei mit dem öffentlichen Stand. Jede Änderung am Programm ist dort mit ihrem ganzen Verlauf sichtbar.

python3 verify.py https://mesh.lehno.de

Das Prüf-Programm braucht nur Python, sonst nichts. Es prüft auch, dass genau diese Dateien an deinen Browser gehen. Am Ende steht entweder „Alles stimmt überein“ oder eine Liste der Abweichungen.

5. Was mit deiner IP-Adresse passiert

Anfragen aus dem normalen Internet laufen durch eine Schleuse, bevor sie die App erreichen. Laut der echten Einstellung dieser Schleuse (vom Server ausgelesen) werden dort diese Angaben entfernt:

lädt …

Die App selbst liest an keiner Stelle eine IP-Adresse oder Gerätekennung aus. Das lässt sich im Quelltext oben nachprüfen.

6. Wer sieht was?

  • Wir als Betreiber: sehen nur verschlossene Blöcke. Nachrichten, Bilder, Sprachnachrichten, Dateien, Kanäle und Verläufe können wir nicht öffnen, weil die Schlüssel nie auf dem Server sind. Die Wörter, der eigene Code und die Kanal-Passwörter verlassen dein Gerät nie.
  • Dein Internetanbieter: sieht, dass dein Gerät mit chatmesh verbunden ist. Nicht, was du schreibst oder an wen. Die App holt ständig alle Blöcke ab und legt Schein-Blöcke ab, egal ob du schreibst. Das macht es von außen sehr schwer zu erkennen, ob und wann du wirklich etwas sendest.
  • Der Netzdienst vor dem Server: Im normalen Internet läuft die Verbindung über einen vorgeschalteten Netzdienst. Er sieht deine IP-Adresse und zählt Zugriffe, sieht aber keine Inhalte. Wer das ausschließen will, nutzt den Tor-Browser.
  • Mit dem Tor-Browser: sieht nicht einmal dein Internetanbieter, dass du chatmesh nutzt, und kein Netzdienst sieht deine IP-Adresse. Anleitung
  • Dein Gegenüber: sieht deine Nachrichten und ob du sie geöffnet hast. Es gibt keine Adresse, keinen Namen und kein Profil.

Ehrliche Grenzen: Die App kommt als Webseite von diesem Server. Deshalb sind Quelltext und Prüf-Programm offen. Das Verschwinden von Nachrichten setzt die App deines Gegenübers um. Bildschirmfotos kann eine Webseite nicht sicher verhindern. Die Blöcke auf dem Server kann jeder abrufen, das gehört zum Verfahren: Niemand kann sie öffnen oder zuordnen, aber wer sie über lange Zeit mitschneidet und später die 12 Wörter und das Kanal-Passwort eines Nutzers bekommt, könnte dessen alte Nachrichten lesen. Wer das ausschließen will, löscht den Kanal und legt einen neuen an.
